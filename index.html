About this table

A structural census of Cas9 and Cas12 effectors: every PDB entry reviewed, the stage of the cleavage cycle it captures, and — for one representative structure per orthologue — the residue-level domain architecture.

Reading the colours

Rows are shaded by CRISPR class, and within a class the two tints alternate per effector (or per subtype) so that a single row stays trackable across the full width of the table.

  • Type II — Cas9
  • Type V — Cas12
  • Context / unassigned

Conventions

“-”
As deposited: the parameter is not reported, or does not apply to that entry. It never means zero.
“None” / “nan”
Placeholders inherited from the generating pipeline, left as deposited.
Links
PDB codes open the structure at RCSB PDB; DOI cells resolve through https://doi.org; PubMed IDs in the raw table open the PubMed record. Every link is derived from the cell — the displayed text is the deposited value.
Domain blocks
Cas9 and Cas12 are tabulated over different domain sets and are therefore kept as two tables rather than one.

Using the page

Search filters the active table across every column. Click a column heading to sort by it, click again to reverse. The first column (or the first two, in the domain tables) stays pinned while you scroll sideways. Columns hides columns you do not need — useful for the 39-column Cas12 table. CSV downloads exactly what is on screen, filters and column choices included.
