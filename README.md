# Pivovarov_et_al_2026
This repository contains supplementary data for "Advances of Cryo-EM and X-Ray Crystallography in the Structural Dissection of CRISPR-Cas effectors of Types II and V"  

The best way to use the interactive HTML version of the table is by this URL: https://georgeegreat.github.io/Pivovarov_et_al_2026/


for usage of jupyter-notebook, ipynb and py file in repository are necessary.
also, environment shoud contain the following libraries:

pandas>=2.0
numpy>=1.24
scipy>=1.10
matplotlib>=3.7
gemmi>=0.6
biopython>=1.81
openpyxl>=3.1
